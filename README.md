# E-Scolarité — prototype frontend

Maquette Angular 21 de la plateforme SaaS E-Scolarité.

## Parcours disponibles

- `/` : site public de la plateforme ;
- `/saas` : console propriétaire, tarification et établissements ;
- `/institut` : back-office d'un établissement souscripteur ;
- `/institut/site-web` : éditeur du site vitrine ;
- `/demo/joyau-du-savoir` : site public généré pour l'établissement.

## Développement

```bash
npm install
npm start
```

## Vérifications

```bash
npm run build
npm run lint
```

Les contenus et données sont volontairement simulés à ce stade. Le prototype sert à valider les parcours, l'organisation de l'information et la direction visuelle avant le branchement au backend.
